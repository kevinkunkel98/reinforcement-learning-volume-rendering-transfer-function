VR rules

Voice-first: command entry and mode state readable at distance. Controller-ready: targets use generous hit areas, visible borders, and no hover-only affordances. Spatial: viewer remains dominant; console can become a floating side panel without changing command hierarchy.

Theme behavior

Light theme uses warm-neutral zinc surfaces. Dark theme uses current zinc tokens and keeps the render black. Toggle changes shell, cards, borders, text, and status contrast; viewer canvas remains black in both themes.
